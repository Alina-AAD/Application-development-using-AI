# Конструктор посещения события

Соберите одноколоночную карточку события с программой и расчётом услуг. Работа объединяет JSON, HTML/CSS и DOM.

## Исходные данные

Сохраните этот блок в `app.js` без изменений. Код обработки напишите самостоятельно.

    const sourceJson = `{
    "event": {
        "title": "Ночь в музее",
        "date": "15 ноября, 18:30",
        "place": "Музей космонавтики, проспект Мира, 111",
        "description": "Вечерняя программа с выставкой и экскурсиями",
        "meeting": "Сбор: 18:30. Начало: 19:00."
    },
    "services": [
        { "id": "guide", "title": "  Экскурсия с гидом  ", "price": 500 },
        { "id": "audio", "title": "Аудиогид", "price": 350 },
        { "id": "catalog", "title": "Каталог выставки", "price": 250 }
    ]
    }`;

# Обязательные требования

## Данные и расчёт

- `sourceJson` разбирается через `JSON.parse()` в `try...catch`, результат называется `data`. Проверять типы отдельных полей не требуется.
- `buildReport(services, guideChecked, audioChecked, catalogChecked)` получает `data.services` и три булевых значения выбора. Используйте `filter` для отбора услуг и `map` для создания нового массива объектов. Внутри `map` извлеките `title` и `price` одноуровневой деструктуризацией и очистите `title` методом `trim()`. Сумму цен посчитайте через `reduce`. Исходные услуги не меняются.
- Отчёт содержит поля `count`, `total` и `items`. В каждом объекте массива `items` ровно два поля: `title` без пробелов по краям и `price`. Пустой выбор: `count: 0`, `total: 0`, `items: []`.

## Страница и действия

`index.html` содержит корректный каркас HTML-документа; соседние `style.css` и `app.js` подключены относительными путями, `app.js` – после разметки. Заголовок, дата, место и описание совпадают с исходными данными; дата, место и описание оформлены абзацами.

| Элемент | Обязательные id и поведение |
|---|---|
| Заголовок `h1` | `event-title` |
| Кнопка «Показать программу» и блок программы | `show-program`, `program`; по клику блок виден, его `innerHTML` равен `data.event.meeting` |
| Форма | `service-form`; чекбоксы `guide`, `audio`, `catalog` с названиями услуг; кнопка `type="submit"` |
| Ошибки | `choice-error`, `data-error` |
| Итог и отдельная JSON-строка | `result`, `report-json` |

Блок программы, форма, области обеих ошибок, итог и JSON-строка изначально имеют атрибут `hidden`. Меняйте их видимость через свойство `hidden`. Находите элементы через `document.querySelector('#id')`. Обработчики событий `click` и `submit` передавайте в `addEventListener()` без вызова. В обработчике `submit` вызовите `event.preventDefault()`, прочитайте `checked` у чекбоксов и вызовите `buildReport`.

`innerHTML` результата: `Выбрано услуг: N<br>Итого: S руб.<br>название 1<br>название 2`. Число названий соответствует выбору, порядок – исходному массиву. В `report-json` покажите только JSON-строку отчёта, полученную через `JSON.stringify()` и проверенную через `JSON.parse()`.

CSS: селектор элемента, минимум два правила для классов, цвета текста/фона, `padding`, `border`, `margin`; видимый внешний промежуток между карточкой и формой. Без Flexbox, Grid, медиазапросов, псевдоклассов, псевдоэлементов, изображений и библиотек.

## Проверка результата

| Проверка | Ожидается |
|---|---|
| Открытие с корректным JSON | Из скрытых областей видна только форма |
| Клик по программе | `Сбор: 18:30. Начало: 19:00.` |
| Только гид / гид и каталог / только аудиогид / все услуги | Соответственно: 1 услуга и 500 руб.; 2 услуги и 750 руб.; 1 услуга и 350 руб.; 3 услуги и 1100 руб. Названия соответствуют выбору и не содержат крайних пробелов; JSON отчёта разбирается без ошибки |
| Пустой выбор после результата | `Выберите хотя бы одну услугу.`; итог и JSON скрыты |
| Непустой выбор после ошибки | Ошибка выбора скрыта, итог и JSON видны |
| Повреждённый JSON: временно удалена двойная кавычка | `Ошибка данных.` в `data-error`, форма скрыта; перед сдачей исходная строка восстановлена |

Закройте и снова откройте `index.html` двойным кликом: страница работает без сервера, перезагрузки при отправке и ошибок в консоли. Проверьте доступность трёх файлов по ссылке без авторизации и вставьте ссылку в ответ на портале.
